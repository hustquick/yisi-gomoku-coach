# 实施计划

## 第一阶段：引擎与规则基线

1. 固定 Rapfi 源码提交和网络权重版本。
2. 在 macOS ARM64 编译命令行 Rapfi。
3. 实现 Piskvork 协议适配器和可取消分析任务。
4. 完成 15×15 棋盘、胜负判断、落子与悔棋单元测试。

## 第二阶段：HTML 教练版

1. 棋盘、候选落点、全局候选箭头与主变化动画。
2. 局面评分、走前/走后评分与局势图。
3. 人机对战、摆盘、历史局面滑移。
4. Rapfi WebAssembly、Web Worker 和离线缓存。

## 第三阶段：iOS 与 Android

1. 复用共享引擎契约实现原生桥接。
2. 复刻 HTML 的交互和教练评价。
3. 按手机性能提供思考时间 / 强度档位。
4. 真机离线测试、耗电测试和安装包验证。

## 完成标准

- 相同局面、规则、引擎版本和限制下，三端首选着法及评分方向一致。
- 计算时可继续操作，新局面不会收到旧任务结果。
- 超时、无合法着法、胜负结束、禁手和权重缺失均有明确状态。
- 分发包内包含 Rapfi GPL-3.0 许可及精确源码版本指针。
