# 弈思五子棋教练 · HTML

当前版本已接入本机 ARM64 Rapfi，可在断网状态下计算全局候选、胜率、评价和主变化。

## Prerequisites

- Node.js `>=22.13.0`

## 启动

```bash
npm install
npm run local
```

打开 `http://localhost:3000`。`npm run local` 会同时启动网页和 `127.0.0.1:3211` 的 Rapfi 适配服务。

Rapfi 默认自动使用最多 4 个 CPU 线程。如需指定线程数，可使用 `RAPFI_THREADS=6 npm run local`；实际线程数不会超过机器的逻辑核心数。

也可以分开启动：

```bash
npm run engine
npm run dev
```

## 当前功能

- 15×15 棋盘、悔棋、重开和胜负判断
- 双人、人机和摆盘模式
- 自由五子棋、标准五子棋和连珠引擎规则
- Rapfi 多候选、胜率、评价、深度和主变化动画；必胜局面会显示杀棋手数，不再误记为 0 分
- 候选着法按当前行棋方的引擎评分从高到低排列；候选栏显示行棋方评分，局势图仍保持统一的黑方视角
- 深度 8、10、12、14、16 可选，思考时仍可落子；先返回所选深度的可靠结果，再在空闲时间继续加深
- 棋盘上方“优”开关显示 Rapfi 多个全局候选落点
- 候选单击演示主变化、双击直接落子
- 黑白视角切换、历史局面前后跳转
- 带黑方视角分数的局势曲线，可点击评分点或拖动滑块回到任意一步；快速落子留下的空缺会在当前分析完成后由后台低深度补算，不以 0 分代替

## 验证

```bash
npm run lint
npm test
```

网页本身可以部署，但当前 Rapfi 是本地原生进程；在线地址不会凭空获得引擎。因此现阶段以本地离线版为准，后续接入 Rapfi WebAssembly 后再发布完整在线版。
